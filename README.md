# Kirlia

Kirlia is a Chrome extension project scaffold for detecting fake news signals and AI-generated content.

## Structure

- `manifest.json`: Chrome extension manifest
- `popup/`: Popup UI files
- `content/`: Content script
- `background/`: Background service worker logic
- `assets/icons/`: Extension icons
- `utils/`: Shared detection utilities and pattern definitions

## Status

This is an initial project skeleton with placeholder icons and empty source files ready for implementation.
